Each cell shows how the opcode manifests in that substrate. The 5 laws (bottom row) are the algebraic properties that hold across all substrates — what makes a cell a cell, not a class.

Polyformalism at a glance

The same cell exists in 6 substrates simultaneously. They differ in:

  • Memory model — Python uses dicts, C uses arrays, Rust uses enums, Verilog uses registers
  • Tick model — Python is event-driven, Verilog is clock-driven, WASM is yield-driven
  • Hash algorithm — FNV-1a 64-bit is the same in all 6 (byte-exact verified)
